# Doing 使用手册

> 适用版本：0.1.0（开发构建，应用标识 `dev.local.chmod777.Doing`）。
> 当前工作区仍处迁移阶段；本轮自动化验证不代表双端原生或正式安装包已验收。详见 `migration-progress.md`。
> 本文与当前实现逐项核对；界面文案以应用内为准。开发与验收状态见仓库根 `README.md`。

## 这是一款什么应用

Doing 是常驻菜单栏（托盘）的任务应用：一个「当前焦点」、一份待办列表、截止时间与到期提醒，
首次使用需要登录，未登录或登出后显示登录页。**事项始终优先保存在本设备**；已登录会话可在断网时继续操作，恢复网络后再同步。本版不提供免登录的离线模式。

## 安装与启动

1. 打开 `Doing_0.1.0_aarch64.dmg`，将 **Doing** 拖入「应用程序」。
2. 首次打开若提示“无法验证开发者”：前往 系统设置 → 隐私与安全性，选择“仍要打开”。
   （当前为未签名/未公证的开发构建；正式分发前将完成签名与公证。）
3. 应用为菜单栏应用（无 Dock 图标）。启动后出现在菜单栏：空闲时显示应用标记，
   有焦点/逾期时显示对应文本。

## 打开与收起面板

- 点击菜单栏图标：展开/收起面板。
- 应用已在运行时再次启动它：唤起面板（单实例）。
- 菜单栏图标右键菜单：打开 Doing / 设置… / （按需）从云端恢复… / 退出登录 / 退出 Doing；
  菜单内显示当前「同步状态」。
- 打开方式（设置 → 通用 → 打开方式）：
  - **菜单栏**：面板贴近菜单栏，失焦自动收起；
  - **桌面浮窗**：窗口停靠在桌面，不自动收起（工作区内点「钉在桌面上」可切换）。
- `⌘W` 收起面板；`⌘Q` 退出。

## 记录与处理事项

- **录入**：在底部输入框输入，回车添加。输入框右侧日历按钮可先为新事项预设截止时间，
  添加后自动清空并回到输入状态。`Esc` 先清空草稿，空草稿时再按才收起面板。
- **完成**：点行首完成框；完成事项折叠在「已完成 · N」中，可展开查看，也可「清除」
  （清除会提示，可撤销）。
- **编辑**：双击事项，或点选后按回车进入编辑；`⌘↩` 或「保存」提交，`Esc` 取消。
- **焦点**：「⋯」菜单 → 设为当前焦点；焦点显示在顶部卡片与菜单栏。
- **截止时间**：点击截止标签或「⋯」→ 设置/修改截止时间；预设（15 分钟后 / 1 小时后 /
  3 小时后 / 明天上午）或自定义日期时间，「移除」清除，「取消」不保存。
- **删除**：选中后按退格，或「⋯」→ 删除事项（可撤销）。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `↩` | 录入框：提交；选中事项时：进入编辑 |
| `↑` / `↓` | 在可见事项间移动选择（录入框内同样可用） |
| `空格` | 完成/恢复选中的事项；编辑器中为正常输入 |
| `⌘↩` | 提交行内编辑 |
| `⌫` | 删除选中事项 |
| `Esc` | 清空草稿 / 退出编辑 / 取消选择 / 收起面板 |
| `⌘N` | 聚焦录入框（快速记录） |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做（编辑器内保留系统原生撤销） |
| `⌘,` | 打开设置 |
| `⌘W` | 主窗口收起；设置窗口关闭 |
| `⌘Q` | 退出 |

## 提醒与通知

- 首版在应用进程运行期间核对到期事项并发送系统通知：标题「已截止」，内容为事项文本；通知声音可在设置关闭，也受系统声音设置控制。
- 设置 → 提醒 → 「系统通知权限」显示「已允许 / 已拒绝 / 尚未请求 / 暂不可用」。启动不自动弹授权框；可点「申请通知权限」，或显式开启提醒后按系统状态申请。拒绝后请在系统设置中更改，再点「重新查询」。
- 未打包或应用身份不匹配时，macOS 通知显示暂不可用，不借用 Terminal 身份、不假报已授权。
- **点击通知**：先打开工作区，登录和数据账号归属确认后定位；任务已完成或改期但仍存在时也会定位，已完成区会自动展开。已删除、未知或已消费的旧通知只打开工作区，不猜测任务。
- 点击定位记录会落盘，应用重启或尚未登录时不依赖一次性的前端事件；界面实际选中并滚动后才确认。其他账号的待定位记录不向当前账号暴露。此前旧插件没有可恢复路由的通知无法补回任务映射。
- 当前已通过隔离逻辑/进程重启测试；新原生链路的真实横幅、声音与安装态热/冷启动点击仍需实机验收。
- 菜单栏显示：当前焦点文本（设置 →「最多显示字数」，1–60）与「⏰ 已逾期」状态。
- 临期突出显示：可设置提前提醒窗口（15 分钟 / 1 小时 / 6 / 24 / 48 小时）；
  到期提醒与「临期提示」相互独立。
- 系统接受通知提交后才保存已提醒记录；投递失败保留提醒资格。记录保存失败时可能用同一稳定 ID 再次提交，不能保证跨崩溃严格只提醒一次。
- 已确认的事项不会重复提醒；恢复为待办/改期会按资格规则重新处理。只提醒当前账号已确认归属的数据。

## 账户与同步

- 注册/登录后，事项通过云端快照在多设备间同步；已登录会话断网后仍可编辑并保存在本机。登出保留事项文件，但工作区需要重新登录。
- 自动同步默认开启；可在 设置 → 账户与同步 关闭（关闭后仍本地保存，可「立即同步」）。
- **冲突保护**：本机与云端都有内容且无法自动判断新旧的场景，会弹出「保留哪一份？」，
  明确选择后另一份才会被替换；可「稍后决定」关闭面板，再从同步详情进入「处理冲突」。未决状态会持久化，重启也不会自动上传覆盖。
- 真正的鉴权失败会回到登录界面；临时网络/服务失败保留凭据等待恢复。安全存储不可用会提示，不回退明文；旧开发版 token-only 记录需要重新登录。
- 换账号/服务地址时保留原数据独立归档，并要求确认本地归属；即使新账号云端为空也不会静默上传旧账号事项。
- 「从云端恢复…」：明确确认后下载云端内容；恢复期间若有新编辑，会转为待确认候选，不覆盖新工作。

## 数据、迁移与回滚

- **数据位置**：`~/Library/Application Support/dev.local.chmod777.Doing/`
  - `data.json`：当前 schema 2 数据，任务修订、dirty、账号归属、已确认基线、未决候选与不确定上传标记同次提交；
  - `data.json.bak`：提交前原子保存的上一次有效内容；备份失败时不会继续覆盖主文件；
  - `settings.json` / `.bak`：schema 1 偏好及备份，包含外观、提醒、打开方式与窗口坐标，保存失败不会先改变设置；
  - `auth-session.json`：仅随机会话 ID/null，不是明文凭据文件；
  - `archives/`：归属变化前的独立数据归档；
  - `migration-state.json`：首次导入的恢复日志与重新登录要求；
  - `migrations/<UUID>/`：来源证明、旧任务/白名单偏好备份、原新版偏好及暂存目标；不要手动删改待恢复事务的文件；
  - 保存采用「临时文件 → 原子替换」，保存失败（如磁盘满、无权限）会明确提示，
    **不会破坏已保存的数据**。失败的任务变更不发布到工作区，录入/编辑草稿保留以便重试。
    若主文件损坏或版本高于当前程序，普通保存会拒绝覆盖，不会把它当作空库重建。
- **设置 → 数据与关于**：
  - 「立即保存」「在 Finder 中显示」；
  - 「导出兼容旧版（回滚用）…」：把当前内容导出为旧版格式，写入数据目录下 `exports/`，
    每次生成独立文件，完整写入后才发布，可在 Finder 中直接取用；失败不覆盖已有导出，也不写回旧版文件位置。
    不支持排他原子发布的文件系统会报错，不会退回直接覆盖写入。
- **从旧版迁移**：检测到旧版数据（`~/Library/Application Support/Doing/items.json`）且新版尚未初始化时，
  面板底部出现导入提示。请先完全退出旧 Swift 版，点「导入」后再次确认；可选择仅导入任务，或同时替换本机新版外观/提醒偏好。
  导入前记录来源校验值并备份，**原文件绝不被修改**，旧 Token 不读取。只接受尚未初始化的新版本地文件，已有内容不能用首次导入覆盖。
  完成后须重新登录并确认账号归属，不会因为云端为空就直接上传。系统通知授权和登录项不继承，应在新版设置中重新确认；旧登录项须待正式切换批准后处理。
- **导入中断或失败**：主面板和设置窗口都会显示恢复入口；未完成前暂停任务、偏好、同步写入和认证恢复。
  「继续恢复」只使用同一事务已核验的备份/暂存；来源已变化时先核对来源，不要手工改日志或强行重复导入。
  「撤销本次导入」需二次确认，仅回退本事务仍拥有的写入，保留旧来源与备份；发现后续修改会停止。
  来源已无法恢复而需要保留当前新版文件时，可单独确认「保留当前文件」；这不等于任务/偏好已全部导入，也不会标记迁移成功。
  备份路径和错误会显示在迁移面板。无法识别的日志不提供危险操作，请先保全整个数据目录再处理。
- **旧浮窗位置**：仅在当前屏幕位置、尺寸、scale 可唯一匹配时转换和恢复；副屏拔出或匹配歧义时使用安全默认位置。真实混合 DPI 行为仍在原生验收范围。
- **回滚**：用「导出兼容旧版」得到的文件配合旧版 Doing 使用；新版本地数据保持不动。

## 卸载

退出后删除应用即可；**用户数据会保留**在 Application Support 中。如需彻底清除，
手动删除数据目录（含 `exports/` 与备份）；同时可在 设置 → 通用 关闭「登录 Mac 时启动」。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 找不到面板 | 重新启动一次应用（单实例会唤起面板）；`⌘N` 聚焦录入框 |
| 同步一直失败 | 检查网络与服务地址；查看 设置 → 账户与同步 的「状态」与错误文案；可「立即同步」重试 |
| 提示「保存失败」 | 检查磁盘空间与数据目录权限；用「立即保存」重试；旧数据仍在 `data.json` / `.bak` |
| 偏好提示保存/格式错误 | 检查 `settings.json` / `.bak` 与权限；损坏或未来版本不会被普通设置操作覆盖，读取失败会暂停自动同步/通知 |
| 收不到通知 | 确认系统通知权限为已允许、且「发送截止通知」开启；勿扰/专注模式会抑制横幅 |
| 迁移提示打扰 | 尚未开始时可选「稍后决定」；待恢复事务不能当普通提示忽略，请先恢复、撤销或确认保留当前文件 |
| 导入提示来源已变化 | 手动退出旧版并核对来源；可撤销后用新来源重试，不要覆盖旧备份或修改日志 |
| 登录状态反复失效 | 检查服务端可用性；重新登录即可，本地数据不受影响 |
